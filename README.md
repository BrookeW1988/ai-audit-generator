# AI Audit Generator

A Claude skill that produces a professional, sellable AI audit + ROI one-pager — the paid-scoping deliverable from the Advisory path. You get paid for the audit itself, whether or not the client buys the build.

## The easy way (Claude Code or Cowork)

1. Download this repo (green **Code** button → Download ZIP) and unzip it.
2. Tell Claude: *"Set this up as a skill for me"* and point it at the folder — or copy the folder into `~/.claude/skills/ai-audit-generator/`.
3. Say **"do an AI audit"** and answer the interview questions. Claude produces the audit + ROI one-pager, ready to format and send.

## Using claude.ai instead?

Open `SKILL.md`, copy the whole thing into a Claude project's instructions, and ask for an AI audit.

## Make it yours

`prompts/build-your-own.md` has a prompt that gets Claude to rebuild this skill around YOUR industry, your voice, and your rates — worth doing once you've run a couple of audits.
