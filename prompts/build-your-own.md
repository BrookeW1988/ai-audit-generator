# Build your own version

Run a few audits with the skill as it is first. Then paste this into Claude (Code or Cowork) to rebuild it around your own corner:

---

I run AI advisory for [YOUR INDUSTRY]. I want my own version of the AI Audit Generator skill.

Here's the skill to start from: [attach the ai-audit-generator folder, or its SKILL.md and references folder]

Rebuild it for me with these changes:
1. The session questions and the business audit method should use the language of [YOUR INDUSTRY]: the tools, the roles, the busy seasons.
2. The report should sound like me. Here's a paragraph I wrote: [PASTE A PARAGRAPH YOU WROTE]
3. The "what to be careful with" section should cover the risks that matter in my industry: [e.g. client confidentiality, compliance, clinical accuracy].
4. If my clients use a different AI setup (not Claude Code), adapt the setup audit's take-stock headings to it: [e.g. ChatGPT custom GPTs, Microsoft Copilot, Zapier].

Keep the parts that make it safe: the prompts only read, keys stay hidden, nothing gets invented, and it stops for my review before building the report. Save it as a skill I can run by saying "do an AI audit".
