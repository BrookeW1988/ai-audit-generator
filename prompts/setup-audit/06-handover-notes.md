# 06 · Handover notes (end of the fix)

**What it's for:** a one-page note per routine, so the owner (or someone else) can look after it.
**Who runs it:** the client. It reads the routines and writes one new file, ROUTINES.md.

Copy from the line below to the end.

---

Write a short note for each of my routines, so I (or someone else) can look after them. Read the routine files, but don't change them. Save the notes as ROUTINES.md in this folder. Never include keys.

For each routine:
- What it does, in one sentence.
- What starts it (me, a schedule, another app) and when.
- What it reads, and where its results go.
- How to tell it worked: what to look for, and where.
- What to do when it doesn't: where the log is, how to re-run it safely, who to ask.
- What it must never do (for example, send an email without a person checking it).

Plain English, no jargon. If you're not sure about something, write "To check" instead of guessing.
