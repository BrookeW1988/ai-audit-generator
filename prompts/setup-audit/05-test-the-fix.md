# 05 · Test the fix (in the fix session, after the audit)

**What it's for:** proving a fix works on one real item before it runs on everything.
**Who runs it:** the client, with you watching. This one does run the routine, on one item only.

Copy from the line below to the end.

---

We've changed [THE WORKFLOW]. Test it on ONE real item before it runs on everything.

1. Pick the oldest item that isn't on the done list yet. Tell me which one, then wait for my OK.
2. Run the routine on that one item only.
3. Check: did it finish without compacting? Did the result land where it should? Was the item added to the done list? If I run it again now, does it skip that item?
4. Add the result to test-log.md in this folder: the date, the item, what worked and what didn't.

Stop after one item. Don't process the rest.
